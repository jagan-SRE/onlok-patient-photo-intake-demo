# Open questions for stakeholder review

## Must know for MVP

- Who is the clinical owner?
- Who will review submissions?
- Which patient fields are required?
- How many photos should be allowed?
- What image types and file size are allowed?
- Should there be one central clinical queue?
- Who can access submissions?
- What statuses are required?
- What does “Charted” mean operationally?
- Where should production photos be stored?
- What is the required retention period?

## Technical / security

- Which Power Platform environment should be used?
- Dataverse or SharePoint/Azure storage?
- What Entra ID groups are required?
- What authentication model is required?
- What audit logging is required?
- What security/privacy approval is required?
- Is a service account required?
- What licenses are required?
- What is the expected production monthly cost?

## Later / optional

- Teams notifications
- Automatic routing by site
- Power Automate workflow
- Adaptive Cards
- Dashboard/reporting
- Automated reminders
- Additional EHR integration
